# Predicción de Diabetes (Pima Indians)

Proyecto de clasificación listo para Google Colab. Incluye EDA, imputación, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/diabetes-prediccion/blob/main/diabetes_prediccion_colab.ipynb)

## Contenido

- EDA (distribución, histograms, correlación)
- Tratamiento de ceros como datos faltantes
- Modelos: Logistic Regression, Random Forest, Gradient Boosting
- Matriz de confusión + Curva ROC
- Feature importance
- **SHAP** (summary + bar plot)
- Conclusiones

Dataset: Pima Indians Diabetes

Rango esperado: Accuracy ~0.75–0.80 | ROC-AUC ~0.82–0.86
